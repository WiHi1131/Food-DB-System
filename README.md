# Food-DB-System
For Final Project in Database Systems

Link to Github repository: https://github.com/WiHi1131/Food-DB-System

YouTube Video Link: https://youtu.be/zCXy2Bls3Sg

In this project for Design and Analysis of Database Systems, I have developed a Flask-based application, hosted on a cloud website known as Render, that primarily serves as a demonstration of my skills and knowledge in database design and management. As the sole architect of this project, I focused on creating a database that not only stores information about various foods but also showcases the intricacies of database systems, including table relationships, data integrity, and advanced query execution.

The core of my project is a PostgreSQL database, carefully designed to reflect a real-world scenario in the context of food data management. The database is not a comprehensive solution but rather a structured framework that lays the groundwork for a potential food tracking and logging application. It consists of several tables, meticulously interconnected, to simulate the kind of complex data relationships one might encounter in a full-fledged culinary application.
